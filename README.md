# 📊 台股籌碼監控儀表板

一個使用 Streamlit 構建的台灣股票籌碼監控系統，可即時追蹤法人買賣超、計算連買天數，並進行智能評分排序。

## ✨ 功能特性

### 1. 📅 日期區間選擇
- 側邊欄設置開始和結束日期
- 靈活查看不同時間段的數據
- 預設顯示最近30天數據

### 2. 📊 法人籌碼分析
- **自動抓取法人資料**（外資、內資、自營商買賣超）
- 實時法人買賣超統計
- 平均買超金額對比分析
- 互動式柱狀圖展示各法人動向

### 3. 📈 連買天數計算
- 自動計算連續買超天數
- Top 10 連買股票排行
- 識別具有持續買超的優質股票

### 4. 🔥 前20熱門股排序
- 按綜合評分自動排序
- 展示完整排行榜
- 評分分布和散點圖分析

### 5. ⭐ 智能評分系統

**評分公式（0-100分）：**
```
評分 = 50 + (外資買超/10)×0.3 + (內資買超/10)×0.2 + (自營商買超/10)×0.2 + (連買天數/5)×0.3
```

**權重分配：**
- 外資買超：30%
- 內資買超：20%
- 自營商買超：20%
- 連買天數：30%

### 6. 📈 K線圖展示
- 互動式蠟燭圖
- 支持多股票同時查看（最多3支）
- 顯示最高價、最低價、收盤價、漲跌幅
- 真實股價數據來自 Yahoo Finance

## 🚀 快速開始

### 1. 環境要求
- Python 3.8+
- pip

### 2. 安裝依賴
```bash
pip install -r requirements.txt
```

### 3. 執行應用
```bash
streamlit run chip_monitor_dashboard.py
```

### 4. 訪問應用
應用將在瀏覽器自動打開，地址通常為 `http://localhost:8501`

## 📋 主要功能模塊

### Tab 1: 法人籌碼
- 三大法人平均買超金額統計
- 法人買賣超對比柱狀圖
- 連買天數Top 10排行
- 最新法人籌碼數據表

### Tab 2: 熱門股票
- 評分排行榜 Top 20
- 評分分布直方圖
- 評分vs連買天數散點圖（氣泡圖）

### Tab 3: K線分析
- 選擇最多3支股票查看K線圖
- 實時股價統計（最高價、最低價、收盤價、漲跌幅）
- 蠟燭圖技術分析

### Tab 4: 詳細資料
- 完整數據表展示
- CSV格式下載功能
- 關鍵統計指標摘要

## 🎨 UI 設計

- **響應式布局**：自動適應不同屏幕尺寸
- **互動式圖表**：Plotly 提供豐富的交互功能
- **數據展示優化**：色彩編碼、格式化數字便於理解
- **用戶友好**：清晰的側邊欄配置面板

## 📊 數據流

```
輸入日期區間
    ↓
生成法人籌碼數據
    ↓
計算連買天數
    ↓
計算綜合評分
    ↓
排序和展示
    ↓
獲取K線數據
    ↓
展示多維度分析結果
```
